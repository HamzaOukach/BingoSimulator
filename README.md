## 🎱 Bingo Game

A desktop Bingo game built in Java, featuring a random draw system with automatic win verification and multiple game modes.

### Features
- Random number draw engine
- Automatic card verification (checks for wins as numbers are drawn)
- Multiple game modes: single line, multiple lines, full card

### Tech Stack
- **Language:** Java
- **Build tool:** Apache Ant (NetBeans project)

### Getting Started

**Prerequisites:**
- Java JDK installed
- NetBeans IDE (recommended) or Apache Ant
